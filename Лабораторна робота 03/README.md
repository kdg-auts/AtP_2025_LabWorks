# Лабораторна робота №3. Програмування числових послідовностей та циклічних процесів

Ознайомтесь з [методичними вказівками](LABWORK3_instructions.md) та знайдіть там таблицю з індивідуальними варіантами. Варіанти розподіляє викладач, таблицю з розподілом має бути прикріплено у завданні в Teams.

Після виконання завдання скористайтесь наведеним шаблоном для оформлення звіту (`Шаблон звіту ЛР 03.docx`). Звіт треба прикріпити до завдання у Teams.
