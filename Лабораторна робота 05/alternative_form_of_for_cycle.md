# Конструкція циклу над діапазоном `for (int num : numbers)`

У мові C++ існує спосіб задавання циклу `for`, який називається **діапазонним циклом** (range-based `for` loop). Він був введений у C++11, а його оголошення має вигляд `for (тип змінна : контейнер)`. Він дозволяє зручно перебирати елементи контейнерів, таких як масиви, вектори, списки та інші колекції.

## Основні особливості діапазонного циклу

1. **Синтаксис**:
   - `for (тип змінна : контейнер) { тіло_циклу; }`, де `тип змінна` — це оголошення змінної, яка має такий самий тип, я і елементи контейнера, а `контейнер` — це структура даних, по якій здйснюється прохід.

2. **Простота**:
   - Діапазонний цикл спрощує код, оскільки вам не потрібно явно вказувати індекси або використовувати ітератори. Це робить код більш читабельним і менш схильним до помилок.

3. **Безпека**:
   - Цей цикл автоматично обробляє межі контейнера, що зменшує ризик виходу за межі масиву або контейнера.

## Приклад використання

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};

    // Діапазонний цикл для перебору елементів вектора
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

У цьому прикладі цикл перебирає всі елементи вектора `numbers` і виводить їх на екран. Кожен елемент вектора присвоюється змінній `num` на кожній ітерації.

### Висновок

Діапазонний цикл є потужним інструментом у C++, який робить перебір елементів контейнерів простішим і безпечнішим. Він особливо корисний, коли вам потрібно просто пройтися по елементах без необхідності змінювати їх або знати їхні індекси.
